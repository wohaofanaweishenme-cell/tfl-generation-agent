# Phase 6.3B pilot
Notebook 15 uses frozen Phase52, Phase62 and Phase63 ZIPs with exact hashes of the uploaded run archives. It does not use Phase61 output as input: it reconstructs a smaller Decision Context from approved JSON and keeps all 9 table templates and 32 presets.
Six fixed cases, A title only, B old scoped passages, C expanded soft-scope passages. B/C per-case chunk count matched to the smaller available list (up to 15); raw character and actual API token usage logged. No new embeddings, no ground truth in prompts. Ranking and candidate selection assessed independently; no generation approval.
Use one Colab session, authorize SAP excerpt transfer and charges in the notebook, and reuse the existing Secret. Persistent per-request attempt reservations in Drive; no SDK retries, no retry of invalid/timeout results, at most 18 attempts under this frozen cache. Interrupted reservations count against budget. Never delete the cache to rerun. Export includes confidential SAP excerpts and raw responses; share only as authorized.
The six cases are developmental, no preset gold labels, and exact quote matching cannot validate clinical applicability. Paired complete-case results plus failure counts, not a generalization claim.
